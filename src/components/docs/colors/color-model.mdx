### Hex Color（16進数カラーコード）とは？

Webで色を指定するための表記方法のひとつ<br />
「光の3原色」赤（R）緑（G）青（B）を0〜255の強さで組み合わせて色を作る<br />
3色の強さを16進数で表す

```txt
#RRGGBB   //基本構造
#FF0000 　//赤
#000000 　//黒
```


<br />
### RGBとは？
光の三原色を使って色を表現する方法

- R（Red）＝赤
- G（Green）＝緑
- B（Blue）＝青

この3つの光を組み合わせて、すべての色を作る<br />
それぞれの値は 0〜255（10進数） で指定

```txt
rgb(赤, 緑, 青) //R + G + B = 色
```

<br />
**RGBA**<br />
RGB（赤・緑・青）に0〜1の透明度（Alpha）を加えた色の表現方法

```css
rgba(赤, 緑, 青, 透明度)
rgba(255, 0, 0, 0.5) //半透明な赤
```

<br />
### HSLとは？

HSLは色を3つの要素で表す方法<br />
RGBより直感的に「人間が理解しやすい色指定」

```txt
HSL = Hue（色相） + Saturation（彩度） + Lightness（明度）
```

**HSLA**<br />
色を「色相（Hue）・彩度（Saturation）・明度（Lightness）」で表し、<br />
さらに0~1の透明度（Alpha）を加えた色の指定方法

```css
hsla(色相, 彩度, 明度, 透明度)
hsla(0, 100%, 50%, 0.5) //半透明の赤
```
