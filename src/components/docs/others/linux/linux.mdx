### Linuxとは？
無料で使える、パソコンやサーバーを動かすOS（基本ソフト）の一種

#### OS (Operating System)
パソコン全体を管理する土台ソフト

- アプリを起動する
- ファイルを保存する
- メモリを管理する
- ネット接続する
- キーボード入力を受け取る

> Windows,<br />
> macOS,<br />
> Linux,<br />
> Android（Linuxベース）,<br />
> iPhoneのiOS（別系統） ...

```txt
例 : FROM node:20-alpine

Linux（Alpine）
Node.js
npm

が入った環境
```

`Dockerコンテナの中身は小さなLinux環境`<br />

```bash
docker exec -it コンテナ名 sh

opt  proc  root run  srv   sys  tmp    usr    var
```

#### よく使う確認コマンド
- サイズ確認
```bash
du -sh /var/*
du -sh /app/*
    4.0K    /app/next.config.js
    892.2M  /app/node_modules
    352.0K  /app/package-lock.json
```

- OS情報
```bash
cat /etc/os-release
    NAME="Alpine Linux"
    ID=alpine
    VERSION_ID=3.23.4
    PRETTY_NAME="Alpine Linux v3.23"
    HOME_URL="https://alpinelinux.org/"
    BUG_REPORT_URL="https://gitlab.alpinelinux.org/alpine/aports/-/issues"
```
