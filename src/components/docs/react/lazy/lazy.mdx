## lazyとは？
**必要になった時だけコンポーネントを読み込む仕組み**

通常はページ表示時にすべてのコンポーネントを読み込むが<br />
`lazy()` を使うと後から必要な時だけ読み込める<br />

**⭐︎初期表示の高速化**<br />
最小限のコードだけでページを表示でき、初期ロード時間が短縮される


**⭐︎読み込み待機の制御**<br />
SuspenseによってローディングUIが明示できる


**⭐︎簡単な導入**<br />
importをReact.lazyに置き換えるだけで導入可能

<br />
**基本構文**<br />
React.lazy() + Suspenseを使う
```jsx
import { lazy, Suspense } from "react";

const UserProfile = lazy(() => import("./UserProfile"));

export default function App() {
    return (
        <Suspense fallback={<p>読み込み中...</p>}>
            <UserProfile />
        </Suspense>
    );
}
```

**⚠️この書き方で読み込めるのはdefault exportされたコンポーネントだけ**
```js
const LoginModal = lazy(() => import("./LoginModal"));


↓  lazy() は内部的に、読み込んだファイルの default を探すため、このような形を期待している


⭕️ export default function LoginModal() {
    return <div>Modal</div>;
}


❌ export function LoginModal() {
    return <div>Modal</div>;
}
lazy() は default を探すため、名前付きexportでは見つからずエラーになる
```

#### 失敗した場合によく出る表示

**① 404 Not Found (ファイルが存在しない)**

**② Failed / net::ERR_ABORTED**
- 通信失敗
- 途中キャンセル
- ネット接続問題

**③ 500 Internal Server Error**
- サーバー側エラー
- Next.js build失敗
- chunk生成ミス
