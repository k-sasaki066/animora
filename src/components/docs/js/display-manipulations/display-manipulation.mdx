### 2. HTMLごと変更 (innerHTML)
#### textContentとの違い

```txt
notice.textContent = "<strong>重要</strong>";

表示結果
<strong>重要</strong>
```
HTMLタグは`文字として表示`される


<br />
#### innerHTMLなら
```txt
notice.innerHTML = "<strong>重要</strong>";

表示結果
重要（太字）
```

⚠️ 外部入力値をそのまま \`innerHTML\` に入れると危険<br />
XSS（悪意あるscript埋め込み）の原因になる
```js
❌ notice.innerHTML = userInput;
```
